# Dungeon Quest v0.5 — Android PWA

## New in v0.5
- Seven original pixel-art character designs: Barbarian, Dwarf, Elf, Wizard, Goblin, Orc and Skaven.
- Distinct equipment, silhouettes, costumes, faces, and two-frame walking/idle motion.
- Nearest-neighbour scaling keeps artwork sharp on high-density Samsung screens.
- Offline PWA cache now includes all character sprites.
- Existing v0.4 saved games remain compatible.
- `character_preview.png` displays all seven characters.

## Play on Android
Host the folder via HTTPS and open it in Chrome or Samsung Internet; install from the browser menu. Local HTML opening may work but offline PWA installation requires HTTPS. No APK is included.

## Rules
Game mechanics remain the simplified v0.4 prototype. These are original fantasy pixel sprites, not copied tabletop artwork.

## Testing
Sprites and ZIP checked locally; not tested on a physical Galaxy S26 Ultra.
